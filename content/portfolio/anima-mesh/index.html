Anima Mesh
The company-of-0 experiment

Jul - Oct 2026 · 3 repos

ad hoc no spec preceded the code. The structure came from releases: 57 tags through v2.4.0, a changelog per minor line, and platform failures written down as learnings.

AnimaMesh runs a mesh of brains with agents. Each brain is one layer of someone's world, kept as a private knowledge bundle: a person's life, a company, or a team or group in between. Agents wake on their own heartbeat, do the preparable work, and bring back a draft to approve or edit. A human remains the approval gate for money, filings, publishing, credentials, and access.

It started as the company-of-0, a company's back office run from one private repo: compliance checks, bookkeeping prep, document memory, governance, research, and inbound triage. Version 2.0 made a brain a layer. Brains link only when both sides agree, the brain that owns the data decides what crosses, and members with roles make a brain multi-player. Since v2.3 a brain can live in a Slack channel, and since v2.4 it can be kept in git, OneDrive, SharePoint, Google Drive, or Dropbox.

Cloud execution is primary. A Worker reads the brain as one tarball, runs the agents that are due, verifies their artifacts, and lands one commit before a brief or reply is sent. The CLI uses the same engine for setup, recovery, and subprocess-only harnesses.

One alarm, then one evidence commit

Defect loop

The brain reports defects on its own engine

A gated report crosses a leak guard, title deduplication, and a per-run cap before it becomes a public issue. The fix returns through a tagged engine release.

Each agent is frontmatter plus prose. Its file carries model, harness, rhythm, sources, read paths, web budget, whitelist, and autonomy level.

Generic engine, isolated company state

The public repo owns reusable logic and tests. Each private instance owns identity, knowledge, credential bindings, deploy configuration, and durable evidence.

Nine agents, one approval gate

From the docs: "the initiative inverts: you stop driving the operations and start reviewing them."

Nine agent concepts run on daily, weekly, monthly, and quarterly rhythms. Due spokes run sequentially; the hub runs last and reads their fresh reports. Discord and Gmail feed direction runs. A separately credentialed dashboard shows the evidence and can trigger a beat. Role-declared reads: paths are inlined into every prompt, with missing context named instead of silently dropped.

Safety lives in code, never in prompts

Everything between wake-up and gate is model judgment. Gates, ladder, ledger, and verifiers are deterministic code.

Five constitutionally gated action classes cover money movement, government filings, publishing, credentials, and access expansion. Three reversible write paths ship today: schedule updates, draft writes, and defect reports. Each request is parsed, checked against the same ladder and whitelist gate, and ledgered whether applied or denied.

The project's own vocabulary

Its own vocabulary · click a word

company-of-0

An organization whose entire back office is run by agents. Humans supply judgment and signatures, nothing else.

the beat

One daily Durable Object alarm. Read the brain, run the due agents, verify in code, commit once, deliver a brief.

autonomy ladder

L1 report-only → L2 draft-for-approval → L3 whitelisted reversible actions → L4 external actions. Promotion is a frontmatter edit with git history as the record.

a direction

An inbound message from the human that becomes one agentic run. The second entry point, budgeted at 20 per day.

propose / dispose

A fenced block in a model's output. Applied only through the gate, always ledgered. Model judgment proposes; deterministic code disposes.

nags

Reminders that ride in every prompt and repeat every beat, with age, until done.

Project context and evidence

What this project collects

Four coordination approaches

Three coordinator systems came before it, each with a different coupling: the continuous agent below, a tightly coupled monolith; the conversion factory's hub and four spokes; and the content factory's loosely coupled A2A mesh. Anima Mesh is the extracted lesson: keep coordination in shared state and model judgment, while deterministic code owns gates, ledgers, verification, and scheduling.

Operational evidence

The private brain records 38 commits authored by the mesh, 330 append-only ledger entries, and 81 reports since July 6. The cloud schedule and the repo history are the evidence surfaces; the portfolio only summarizes them.
