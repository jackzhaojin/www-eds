Privacy policy

How my personal tools handle data from a Google account. Last updated October 10, 2026.

Who this covers

This policy covers personal software I build and run for myself, including brain-jzj, a private assistant that prepares my own daily brief. These tools have one user: me. They are not offered to the public, and no one else can sign in to them.

What Google data is accessed

With my consent, brain-jzj reads my own Google account with read-only permissions:

  • Gmail (read-only): recent message headers and short snippets, and a full message only when I ask for it.
  • Google Calendar (read-only): event titles, times, and places for a short window around today.

It cannot send, delete, label, or change email, and it cannot create or change calendar events.

How the data is used

The data is used only to prepare reminders and a daily summary for me. Account numbers, card numbers, one-time codes, and passwords are removed in code before anything else sees them. Summaries are stored in my own private repository.

Sharing

Google data is never sold, never used for advertising, and never shared with anyone else. To write my summary, text may be processed by the AI model provider I use (Anthropic), under that provider's terms, solely to produce output for me.

Limited Use

The use and transfer of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

Access tokens are stored only on my own machine and in my own encrypted cloud secrets. Access can be revoked at any time from Google Account permissions, which stops all further reads.

Contact

Questions about this policy: reach me through LinkedIn or GitHub.
