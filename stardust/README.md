# stardust: the migration's records and instruments

Everything the same-design migration produced or ran, kept so the work can be checked and repeated. Most of it was written by Adobe's [stardust](https://github.com/adobe/skills) plugin (0.36.0, flow `replica`). The importers and a few checks were written for this site. Nothing here is served (`.hlxignore`). Heavy captures and screenshots are git-ignored (`.gitignore` in this folder); they're regenerated by re-running a gate.

## Scripts

`scripts/` is where stardust's setup copies its scripts, so the gates run without the plugin installed. The scripts written for this site are listed separately below.

| Path | What it does |
|---|---|
| `scripts/replica/` | the gate: `gate.sh` (one round: stitched pixel diff with band breakdown, plus content-diff, visual-diff, chrome parity, clip and overflow on `--full`), `gate-all.mjs` (every page), `measure.mjs`, `cap-probe.mjs`, `run-bg.mjs` (background rounds with deadlines) |
| `scripts/diff/` | content-diff and visual-diff with their profiles |
| `scripts/deploy/` | the DA side: `deploy-batch.mjs` (PUT, preview, publish, with a ledger), `da-media-upload.mjs`, `localize-links.mjs`, `ew-editability-probe.mjs` |
| `scripts/extract/`, `scripts/spec/`, `scripts/dynamics/`, `scripts/migrate/`, `scripts/stardust/`, `crawl.mjs`, `thumb.mjs` | the rest of the stardust pipeline |

Written for this site:

| Script | What it does |
|---|---|
| `scripts/import-article.mjs` | one GitHub Pages article into an Experience Workspace document for the article template |
| `scripts/import-engines/` | 43 importer engines, one per explainer kind (`match()` and `convert()`) |
| `scripts/import-listing-pages.mjs`, `import-portfolio.mjs`, `import-design-system.mjs` | the listing pages, the portfolio and the design system site |
| `scripts/seo-check.mjs` | the SEO check of every sitemap page on a host: head tags, JSON-LD, and every JSON-LD, social image and internal link URL answering 200 (`content/README.md`, step 5) |
| `scripts/fix-dead-image-urls.mjs` | swaps the old site's `/writing/<slug>/images/…` URLs in content for the media copy www serves, after matching the bytes against gh |
| `scripts/pull-media.mjs` | pulls media files from DA into `content/media/` and checks each is byte-identical to the copy the site delivers |
| `scripts/roundtrip-compare.mjs`, `scripts/roundtrip-batch.mjs` | the editor round trip: compare two DA documents by content and by markup (the editor's known rewrites undone), and run uploads and collection for many pages (`content/README.md`, step 3) |
| `scripts/sync-head-metadata.mjs` | copies each www page's SEO head (JSON-LD, titles, article tags) into its document's metadata |
| `scripts/rollout-gate-state.mjs` | builds the gate state for the final sweep |
| `scripts/v3-eval.mjs` | design system v3's contrast eval, run on EDS pages in all three themes |

Gate captures are written to `replica/gates/<page>-<width>/` (git-ignored). Deleting a gate's `live.png`, `live.capture.json` and `chrome-live.json` makes the next round recapture the source.
